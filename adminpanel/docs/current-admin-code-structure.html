Current Admin Code Structure

Controller.php

শুধু perPage(Request $request) আছে। এটি 10, 20, 50, 100 ছাড়া অন্য value reject করে।

Admin, Section, Category, Setting Controllers

প্রতিটি list select(...)->cursorPaginate($this->perPage($request))->through(...) ব্যবহার করে। select শুধু প্রয়োজনীয় database field নেয়, cursorPaginate বড় data-তে COUNT/OFFSET এড়ায়, through current rows map করে view-এর জন্য ছোট payload বানায়। Admin CRUD page-এ cache নেই; তাই data সবসময় fresh।

layout.blade.php

  • loadAjaxPage: sidebar/pagination URL AJAX-এ আনে এবং শুধু main content replace করে।
  • data-server-per-page: 10/20/50/100 পরিবর্তন করে, page reset করে।
  • data-table-export: visible rows CSV (Excel) অথবা DOC (Word) download করে।
  • data-crud-*: reusable create/edit/status/delete AJAX handler।

অপ্রয়োজনীয় DataTables initialization এবং refresh logic সরানো হয়েছে। Server pagination-ই একমাত্র pagination।

Views

Users, Sections, Categories, Settings table-এর উপরে Show selector এবং Excel/Word button। নিচে একবার Laravel cursor pagination link।
