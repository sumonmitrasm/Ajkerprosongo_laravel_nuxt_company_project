৩. Database migration: posts table

File: database/migrations/YYYY_MM_DD_create_posts_table.php

Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('category_id')->constrained()->restrictOnDelete();
    $table->foreignId('admin_id')->nullable()->constrained('admins')->nullOnDelete();
    $table->string('title');
    $table->string('slug')->unique();
    $table->string('short_title')->nullable();
    $table->text('excerpt')->nullable();
    $table->longText('content');
    $table->string('image')->nullable();
    $table->string('image_alt')->nullable();
    $table->enum('status', ['draft', 'published', 'archived'])->default('draft');
    $table->timestamp('published_at')->nullable();
    $table->string('meta_title')->nullable();
    $table->text('meta_description')->nullable();
    $table->string('meta_keywords')->nullable();
    $table->string('canonical_url')->nullable();
    $table->timestamps();
    $table->index(['status', 'published_at']);
    $table->index(['category_id', 'status', 'published_at']);
});
Index খুব গুরুত্বপূর্ণ: homepage এবং category page সাধারণত published status ও published_at দিয়ে filter করে। এই composite indexes না থাকলে post বড় হলে query slow হবে।

৪. Model: Post.php

File: app/Models/Post.php

class Post extends Model
{
    protected $fillable = ['category_id','admin_id','title','slug','short_title','excerpt','content','image','image_alt','status','published_at','meta_title','meta_description','meta_keywords','canonical_url'];
    protected $casts = ['published_at' => 'datetime'];
    public function category(): BelongsTo { return $this->belongsTo(Category::class); }
    public function author(): BelongsTo { return $this->belongsTo(Admin::class, 'admin_id'); }
    public function scopePublished($query) { return $query->where('status', 'published')->whereNotNull('published_at')->where('published_at', '<=', now()); }
}

scopePublished() ব্যবহার করলে একই publish rule homepage, category page ও single page-এ copy করতে হয় না।

৫. Routes

File: routes/web.php; admin.auth ও admin.permission middleware-এর ভিতরে রাখবেন।

Route::get('posts', [PostController::class, 'index'])->name('admin-post');

Middleware map-এ admin-post = view, store = add, update/status = edit, delete = delete permission যোগ করবেন।

৬. Admin list: huge data-এর correct pattern

PostController::index(Request $request)-এ বর্তমান project-এর reusable cachedPage() ব্যবহার করবেন:

$posts = $this->cachedPage($request, 'admin.posts.index', fn () =>
    Post::with(['category:id,category_name','author:id,name'])->latest('id'),
    fn (Post $post) => [
        'id' => $post->id,
        'title' => $post->title,
        'slug' => $post->slug,
        'category_name' => $post->category?->category_name,
        'author_name' => $post->author?->name,
        'status' => $post->status,
        'published_at' => optional($post->published_at)->format('Y-m-d H:i'),
    ]
);

এটি প্রতি page-এ 25 row query/cache করে। Post::get() দিয়ে সব post load করবেন না।

৭. Cache key ও invalidation

Base Controller page keys বানাবে: admin.posts.index.{version}.page.{number}। Post create/update/delete/status হওয়ার পর:

$this->invalidateCachedPages('admin.posts.index');
Cache::forget('public.homepage.v1');
Cache::forget('public.category.' . $post->category_id . '.v1');
Cache::forget('public.post.' . $post->slug . '.v1');

Admin list এবং public cache আলাদা রাখবেন। Public cache key-তে language, page, category বা slug থাকলে সেই অংশ key-তে রাখবেন।

৮. Store/update validation

$data = $request->validate([
    'category_id' => ['required', 'exists:categories,id'],
    'title' => ['required', 'string', 'max:255'],
    'excerpt' => ['nullable', 'string', 'max:1000'],
    'content' => ['required', 'string'],
    'image' => ['nullable', 'image', 'mimes:jpeg,jpg,png,webp', 'max:4096'],
    'status' => ['required', Rule::in(['draft','published','archived'])],
    'published_at' => ['nullable', 'date'],
    'meta_title' => ['nullable', 'string', 'max:255'],
    'meta_description' => ['nullable', 'string'],
]);

Server-side validation বাধ্যতামূলক। Browser validation কখনো security নয়। Slug server-এ Str::slug($data['title']) দিয়ে তৈরি করে unique check করবেন।

৯. Image upload

public_path()-এ random file রাখার বদলে Laravel disk ব্যবহার ভালো:

$path = $request->file('image')->store('posts', 'public');
$data['image'] = $path;

Server-এ একবার php artisan storage:link চালাতে হবে। Image change/delete হলে পুরোনো file Storage::disk('public')->delete($post->image) করবেন। বড় site-এ পরে S3/Cloudflare R2 disk ব্যবহার করা যায়; controller code একই থাকবে।

১২. Post publish workflow

Draft save→Admin edit→Status = published→published_at = now→DB save→Admin/public cache invalidate→Homepage/category/news page fresh

Future publish schedule হলে cron/scheduler প্রতি minute-এ scheduled post publish করবে এবং একই cache invalidation চালাবে।

১৩. Security ও quality checklist

  • HTML editor থাকলে XSS sanitation policy ঠিক করুন; raw user HTML সরাসরি render করবেন না।
  • Slug route-এ unpublished post public user-কে দেখাবেন না।
  • Image MIME, size এবং dimensions validate করুন।
  • Authorization: editor শুধু নিজের post edit করবে কি না business rule ঠিক করুন।
  • Database transaction ব্যবহার করুন যেখানে post save ও related records একসঙ্গে save হয়।
  • Soft delete লাগলে migration/model-এ softDeletes() দিন।
  • Public page N+1 query এড়াতে with('category') ব্যবহার করুন।
