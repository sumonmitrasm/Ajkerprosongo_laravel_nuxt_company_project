2. প্রথম কাজ: Permission page-এ module কীভাবে show হয়?

আপনি যদি শুধু module name দেখাতে চান: প্রথমে database-এর admin_roles table-এ ওই module name থাকতে হবে। এরপর permission page automatic সেটি দেখাবে।

Step 2.1 — Database check করুন

phpMyAdmin → admin_roles → দেখুন module column-এ এই values আছে:

admin
section
category

এই তিনটি value থাকলে Permission page-এ দেখাবে:

Admin Management
Section Management
Category Management

Step 2.2 — কোন code database থেকে module নেয়?

File খুলুন:

app/Http/Controllers/AdminController.php

permissionUser() method-এ এই code আছে:

$modules = AdminRole::query()
    ->select('module')
    ->distinct()
    ->orderBy('module')
    ->pluck('module');

এর অর্থ: সব row থেকে duplicate বাদ দিয়ে শুধু module নামগুলো নেয়। যেমন table-এ 20টি section row থাকলেও page-এ Section একবারই দেখাবে।

Step 2.3 — Blade file কী করে?

File খুলুন:

resources/views/admin/accounts/partials/admin-permission.blade.php

এখানে এই loop আছে:

@foreach ($modules as $module)
    <h5>{{ ucfirst($module) }} Management</h5>
    {{-- View, Add, Edit, Delete, Full, No Access checkboxes --}}
@endforeach

তাই এখানে admin, section, category manually add করার দরকার নেই।

3. দ্বিতীয় কাজ: Save চাপলে database-এ কীভাবে যায়?

Checkbox select
Permission form
AJAX POST
AdminController
admin_roles update

Step 3.1 — Checkbox field name

admin-permission.blade.php-এ input name এমন হয়:

permissions[section][view_access]
permissions[section][add_access]
permissions[section][edit_access]
permissions[section][delete_access]
permissions[section][no_access]

অর্থাৎ Section-এর View checkbox select হলে request-এ permissions[section][view_access] = 1 যায়।

Step 3.2 — Controller database save করে

File:

app/Http/Controllers/AdminController.php

Method: updatePermissionUser()

AdminRole::updateOrCreate(
    ['admin_id' => $user->id, 'module' => $module],
    [
        'view_access' => 1 or 0,
        'add_access' => 1 or 0,
        'edit_access' => 1 or 0,
        'delete_access' => 1 or 0,
        'no_access' => 1 or 0,
    ]
);

updateOrCreate মানে: ওই user + ওই module-এর row থাকলে update, না থাকলে create।

Step 3.3 — Full Access / No Access

আপনি যা select করবেনDatabase-এ কী save হবে
Full Accessview_access=1, add_access=1, edit_access=1, delete_access=1, no_access=0
Module No Accessview_access=0, add_access=0, edit_access=0, delete_access=0, no_access=1
শুধু View Accessview_access=1; বাকি সব 0
খুব গুরুত্বপূর্ণ: আপনার আসল table-এ full_access column নেই, আছে delete_access। Full Access checkbox শুধু shortcut; এটি চারটি access একসাথে 1 করে।

4. তৃতীয় কাজ: Layout-এ permission save-এর code কোথায়?

File খুলুন:

resources/views/admin/layout/layout.blade.php

Step 4.1 — AJAX form submit

এই selector permission form ধরছে:

$(document).on('submit', '#permission-form', function (event) {
    event.preventDefault();
    // AJAX দিয়ে save request পাঠায়
});

এখানেই event.preventDefault() থাকার কারণে Save করলে browser reload হয় না।

Step 4.2 — SweetAlert message

crudToast('success', response.message || 'Permissions updated successfully.');

এটি save successful হলে SweetAlert toast দেখায় এবং নিজে থেকেই disappear হয়।

Step 4.3 — Full Access checkbox shortcut

একই file-এ data-full-access JavaScript আছে। আপনি Full Access tick করলে View/Add/Edit/Delete automatic tick হবে। No Access tick করলে অন্য সব untick হবে।

5. চতুর্থ কাজ: Sidebar menu কীভাবে hide/show হয়?

File খুলুন:

resources/views/admin/layout/sidebar.blade.php

Top-এর দিকে এই 3টি variable আছে:

$canManageAdmins = $admin?->hasModuleAccess('admin', 'view');
$canManageSections = $admin?->hasModuleAccess('section', 'view');
$canManageCategories = $admin?->hasModuleAccess('category', 'view');
Database moduleSidebar menuকোন variable
adminAccount → Users$canManageAdmins
sectionPages → Sections$canManageSections
categoryPages → Category$canManageCategories

যদি view_access=0 অথবা no_access=1 হয়, hasModuleAccess(..., 'view') false দেয়। তখন ওই menu show হবে না।

6. পঞ্চম কাজ: শুধু menu hide নয়, URL-ও কীভাবে বন্ধ হয়?

File খুলুন:

app/Http/Middleware/AdminPermissionMiddleware.php

এই file-এ route name-এর সঙ্গে module/action match করা আছে:

'section' => ['section', 'view'],
'admin-section.store' => ['section', 'add'],
'admin-section.update' => ['section', 'edit'],
'admin-section.delete' => ['section', 'delete'],

তারপর middleware hasModuleAccess($module, $access) চালায়। Permission না থাকলে HTTP 403 দেয়।

এই middleware route-এ কীভাবে চালু আছে?

File:

routes/web.php

Route::middleware(['admin.auth', 'admin.permission'])->group(function () {
    // Users, Sections, Category routes এখানে আছে
});

নতুন protected route-ও এই group-এর মধ্যে রাখবেন।

7. নতুন module add করার পুরো step

উদাহরণ: আপনি News নামে নতুন module বানাবেন। Module key হবে news।

Step 7.1 — আগে News-এর page/route/controller তৈরি করুন

Laravel route অবশ্যই named route হতে হবে। উদাহরণ:

Route::get('news', [NewsController::class, 'index'])->name('news');
Route::post('news', [NewsController::class, 'store'])->name('admin-news.store');
Route::put('news/{news}', [NewsController::class, 'update'])->name('admin-news.update');
Route::delete('news/{news}', [NewsController::class, 'destroy'])->name('admin-news.delete');

Step 7.2 — Database-এ একবার module name ঢোকান

phpMyAdmin → admin_roles → Insert। একটি existing superadmin-এর জন্য row দিন:

admin_id: 1                 // আপনার superadmin ID
module: news
view_access: 1
add_access: 1
edit_access: 1
delete_access: 1
no_access: 0

এখন Permission page refresh করলে News Management automatic দেখাবে। কারণ controller database থেকে distinct module name নেয়।

Step 7.3 — Middleware-এ News route add করুন

File:

app/Http/Middleware/AdminPermissionMiddleware.php

permissionForRoute() method-এ যোগ করুন:

'news' => ['news', 'view'],
'admin-news.store' => ['news', 'add'],
'admin-news.update' => ['news', 'edit'],
'admin-news.delete' => ['news', 'delete'],

Step 7.4 — Sidebar-এ News menu add করুন

File:

resources/views/admin/layout/sidebar.blade.php

Variable add করুন:

$canManageNews = $admin?->hasModuleAccess('news', 'view');

তারপর Pages menu-র ভিতরে add করুন:

@if ($canManageNews)
    <li><a href="{{ route('news') }}" class="slide-item">News</a></li>
@endif

Step 7.5 — News page-এর Add/Edit/Delete button control করুন

News Blade file-এর শুরুতে:

@php
    $currentAdmin = Auth::guard('admin')->user();
    $canAddNews = $currentAdmin?->hasModuleAccess('news', 'add');
    $canEditNews = $currentAdmin?->hasModuleAccess('news', 'edit');
    $canDeleteNews = $currentAdmin?->hasModuleAccess('news', 'delete');
@endphp

Button-এর চারপাশে ব্যবহার করুন:

@if ($canAddNews)
    <button>Add News</button>
@endif

@if ($canEditNews)
    <button>Edit</button>
@endif

@if ($canDeleteNews)
    <button>Delete</button>
@endif
এই 5টি step শেষ হলে News module পুরো permission system-এ কাজ করবে।

8. কাজ শেষে test করার নিয়ম

  1. একটি non-superadmin user নিন।
  2. Section → শুধু View Access দিন → Save করুন।
  3. ওই user দিয়ে login করুন। Sidebar-এ Sections দেখাবে, কিন্তু Add/Edit/Delete button দেখাবে না।
  4. তারপর Full Access দিন → চারটি action button কাজ করবে।
  5. তারপর Module No Access দিন → Sections sidebar থেকে চলে যাবে। Direct URL দিলে 403 হবে।

php artisan optimize:clear
