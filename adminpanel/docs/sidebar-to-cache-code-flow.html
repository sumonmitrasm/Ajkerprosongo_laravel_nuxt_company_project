Sidebar → Category → Cache: Code Flow

Sidebar-এ Category click করার পর কোন file-এর কোন code কীভাবে চলে

এক নজরে সম্পূর্ণ flow

1. Sidebar Category link→2. layout.js click handler→3. GET /admin/category→4. Route→5. CategoryController::category()→6. cachedPage()→7. Redis/DB→8. Blade table HTML→9. AJAX content replace

Step 1 — Sidebar link

File: resources/views/admin/layout/sidebar.blade.php

<a href="{{ route('category') }}" class="slide-item">Category</a>

route('category') Laravel থেকে URL তৈরি করে: /admin/category। Browser সাধারণভাবে এই URL open করতে চাইবে।

Step 2 — layout.blade.php click ধরে

File: resources/views/admin/layout/layout.blade.php

$(document).on('click', '.side-menu a[href]', function (event) {
    event.preventDefault();
    window.loadAjaxPage(url.href, true);
});

এখানে preventDefault() browser-এর full-page navigation বন্ধ করে। তারপর loadAjaxPage() AJAX request পাঠায়। তাই sidebar click করলেও header/sidebar reload হয় না; শুধু main content বদলায়।

Step 3 — AJAX request

$.ajax({ url: '/admin/category' })

এটি একই Laravel route-এ GET request। AJAX হওয়ায় Controller আলাদা নয়; সাধারণ page request-এর মতোই একই route ও controller চলে।

Step 4 — Route controller বেছে নেয়

File: routes/web.php

Route::get('category', [CategoryController::class, 'category'])
    ->name('category');

URL /admin/category হলে Laravel CategoryController-এর category(Request $request) method call করে।

Step 5 — CategoryController cachedPage call করে

File: app/Http/Controllers/CategoryController.php

$categories = $this->cachedPage(
    $request,
    'admin.categories.index',
    fn () => Category::with('section', 'parentcategory')->latest('id'),
    fn (Category $category) => [
        'id' => $category->id,
        'category_name' => $category->category_name,
        'section_name' => $category->section?->name,
    ]
);

এখানে Controller নিজে সব cache code লিখছে না। $this মানে বর্তমান CategoryController, যা base Controller.php inherit করেছে। তাই cachedPage() method পাওয়া যায়।

Step 6 — Controller.php cachedPage কী করে?

File: app/Http/Controllers/Controller.php

লাইন/ধাপকাজ
$page = request pageURL-এর ?page=2 থেকে page number নেয়; না থাকলে 1।
$version = Cache::get(...version)বর্তমান cache version নেয়।
$key = prefix.version.pageযেমন: admin.categories.index.abc-uuid.page.2।
$payload = Cache::get($key)Database cache বা Redis cache থেকে page-এর data আনে।
payload validDatabase query ছাড়াই cache-এর 25 row ফেরত দেয়।
payload miss/invalidpaginate(25) query করে, model map করে plain array বানায়, তারপর 6 ঘণ্টার জন্য cache করে।
LengthAwarePaginatorBlade-এর $categories->links() কাজ করার জন্য paginator object বানায়।

Step 7 — কেন plain array?

$map callback Eloquent Category model থেকে শুধু দরকারি field নেয়। Redis/database cache-এ Category object রাখা হয় না। তাই পুরোনো __PHP_Incomplete_Class এবং object/string mismatch error এড়ানো যায়।

Step 8 — Blade table HTML বানায়

File: resources/views/admin/category/partials/get-category.blade.php

@foreach ($categories as $category)
    <td>{{ $category['category_name'] ?? '-' }}</td>
@endforeach

{{ $categories->links() }}

Controller থেকে পাওয়া paginator-এর items table row বানায়। links() next/previous/page-number link তৈরি করে। Table-এ data-server-pagination থাকায় DataTables এই table-কে আবার client-side paginate করে না।

Step 9 — layout AJAX response বসায়

var $newContent = $response.find('#ajax-page-content').first();
$content.html($newContent.html());

Laravel full HTML response দিলেও JavaScript শুধু #ajax-page-content-এর ভিতরের নতুন Category table নেয় এবং পুরোনো main content replace করে। Header ও sidebar একই থাকে।

Pagination click হলে flow

Category page 2 click→layout-এর .pagination a handler→/admin/category?page=2→CategoryController→cachedPage(page 2 key)→new table HTML

Page 1 এবং page 2-এর cache key আলাদা, তাই সব category একসঙ্গে load হয় না।

Add/Edit/Delete-এর পর কী হয়?

Category update-এর পর clearCategoryCache() চলে এবং invalidateCachedPages('admin.categories.index') নতুন version UUID সেট করে। পরের request পুরোনো page cache key নয়, নতুন key ব্যবহার করে। একই pattern Users, Sections এবং Settings-এও ব্যবহৃত হয়েছে।

মনে রাখার সহজ নিয়ম

Sidebar শুধু URL দেয়। Layout JavaScript URL-কে AJAX request-এ পাঠায়। Route Controller method বেছে দেয়। Module Controller cachedPage call করে। Controller.php cache/DB/pagination কাজ করে। Blade HTML বানায়। Layout সেই HTML main area-তে বসায়।
