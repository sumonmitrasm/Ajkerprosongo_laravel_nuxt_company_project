Pagination & Export: Step by Step

Show 10/20/50/100 এবং Excel/Word download কীভাবে কাজ করে

১. আগে কী সমস্যা ছিল?

আগে server-side pagination-এ প্রতি page 25 row ছিল। Screenshot-এ 11 user থাকায় সব 11 row এক page-এ ছিল; Laravel দ্বিতীয় page না পেয়ে pagination link দেখায়নি।

২. Controller.php: per-page value নেওয়া

File: app/Http/Controllers/Controller.php

$perPage = (int) $request->query('per_page', 10);
$perPage = in_array($perPage, [10, 20, 50, 100], true) ? $perPage : 10;

URL-এ ?per_page=50 থাকলে 50 row আসে। URL value অন্য কিছু হলে নিরাপত্তার জন্য default 10 নেওয়া হয়। এই whitelist database overload ঠেকায়।

৩. Cache key কেন বদলানো হয়েছে?

$key = $prefix . '.' . $version . '.per-page.' . $perPage . '.page.' . $page;

10 row/page এবং 50 row/page-এর result এক নয়। তাই আলাদা cache key লাগে:

admin.users.index.UUID.per-page.10.page.1≠admin.users.index.UUID.per-page.50.page.1

এতে পুরোনো 25-row cache নতুন 10-row table-এ ভুলভাবে দেখায় না।

৪. Blade selector

Users, Sections, Categories ও Settings list-এর নিচে এই selector যোগ হয়েছে:

<select data-server-per-page>
  <option value="10">10</option>
  <option value="20">20</option>
  <option value="50">50</option>
  <option value="100">100</option>
</select>

বর্তমান URL-এর per_page value অনুযায়ী selected option দেখায়।

৫. Selector change-এর JavaScript flow

File: resources/views/admin/layout/layout.blade.php

$(document).on('change', '[data-server-per-page]', function () {
    var url = new URL(window.location.href);
    url.searchParams.set('per_page', this.value);
    url.searchParams.delete('page');
    window.loadAjaxPage(url.href, true);
});
User: Show 50→URL: ?per_page=50→page reset to 1→AJAX request→cachedPage(50)→50 rows render

Page reset করা হয় কারণ user হয়তো 10-row/page-এর page 20-তে ছিল; 50-row/page করলে সেই page number আর valid নাও হতে পারে।

৬. Excel export কী করে?

Users table-এ Excel button-এর data-table-export="#users-table" আছে। JavaScript table-এর বর্তমানে visible row ও header পড়ে CSV content তৈরি করে এবং download করে।

data-table-export="#users-table"
data-table-export-type="excel"

Download file-এর extension .csv। Microsoft Excel এটি সরাসরি open করতে পারে। UTF-8 BOM ব্যবহার করা হয়েছে, তাই বাংলা text ঠিকভাবে দেখার সম্ভাবনা বেশি।

৭. Word export কী করে?

Word button বর্তমান table HTML একটি file-এ নিয়ে .doc হিসেবে download করে। Microsoft Word এটি open করতে পারে।

গুরুত্বপূর্ণ: Export বর্তমানে visible page-এর rows নেয়। যেমন Show 10 হলে 10 row, Show 50 হলে 50 row export হবে। Huge database-এর সব data browser-এ এনে export করা হয় না—এটি performance-এর জন্য ইচ্ছাকৃত। পুরো database Excel/XLSX export লাগলে আলাদা server-side export route এবং Laravel Excel package যোগ করতে হবে।
