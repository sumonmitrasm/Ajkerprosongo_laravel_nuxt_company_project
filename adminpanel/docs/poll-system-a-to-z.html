1. পুরো flow

Admin form → JavaScript AJAX request → web route → PollController validation/transaction → Eloquent Models → MySQL। Success হলে modal বন্ধ হয়ে list AJAX-এ refresh হয়।

Blade→polls.js→web.php→Controller→Models→Database

বর্তমান scope: এটি admin web module; public/Nuxt API এখনো করা হয়নি।

4. Model relationships

// Poll.php
public function options(){ return $this->hasMany(PollOption::class); }
public function votes(){ return $this->hasMany(PollVote::class); }
public function comments(){ return $this->hasMany(PollComment::class); }
public function correctOption(){
 return $this->belongsTo(PollOption::class,'correct_option_id');
}

// PollOption.php
public function poll(){ return $this->belongsTo(Poll::class); }
public function votes(){ return $this->hasMany(PollVote::class); }

withCount(['options','votes','comments']) full records না এনে count আনে—বড় list-এর জন্য efficient।

8. Correct answer

নতুন option-এর database ID আগে নেই। Browser index পাঠায়:

options[0][content] = "হ্যাঁ"
options[1][content] = "না"
correct_option_index = 1
index 1→option save→real ID 27→correct_option_id 27

Edit-এর hidden options[index][id] দিয়ে পুরোনো option update, ID ছাড়া option create হয়। reindexOptions() A/B/C labels ও input names ঠিক করে।

9. CRUD flows

Create

  1. Empty modal ও minimum 2 options
  2. JS POST FormData
  3. Validation ও transaction
  4. AJAX list refresh

Edit

  1. data-url-এ GET
  2. show() JSON
  3. JS form fill
  4. _method=PUT

Status/Delete

Status-এর জন্য PATCH। Confirmation-এর পরে DELETE; cascade related rows এবং Controller image remove করে।

Vote safety: বাদ দেওয়া old option-এ vote থাকলে delete আটকায়, তাই historical vote নষ্ট হয় না।

10. Permission, status ও Nuxt future

  • CSRF, validation, DB transaction
  • poll view/add/edit/delete permission
  • pagination ও withCount
  • Draft: review/অসম্পূর্ণ; public নয়
  • Published: schedule valid হলে public
  • Closed: voting শেষ

পরে admin/database রেখে API করা যাবে:

GET /api/polls
GET /api/polls/{slug}
POST /api/polls/{poll}/votes
GET /api/polls/{poll}/results
POST /api/polls/{poll}/comments

Nuxt side-এ published status, schedule, result visibility, duplicate-vote rule ও rate limit লাগবে।

11. Debug ও change checklist

  1. php artisan route:list --name=poll
  2. Network tab: URL, method, status
  3. 422 = validation; 500 = storage/logs/laravel.log
  4. Blade/JS selector spelling
  5. migration, foreign keys ও permission

নতুন field: migration + Blade name + validation + controller + model মিলান। নতুন action: route + permission + selector + JS request মিলান। শেষে create/edit/status/delete test করুন এবং নতুন code-এর কাজে comment দিন।

মনে রাখার সূত্র

Blade → JavaScript → Route → Controller → Model → Database। এই ছয় জায়গার field name, URL, HTTP method এবং ID/class একই contract মেনে চললেই module ঠিক কাজ করবে।
