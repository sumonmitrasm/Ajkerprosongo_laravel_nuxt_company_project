Laravel AJAX User CRUD

Page reload ছাড়া Add, Edit, Delete ও Status Update করার সহজ গাইড

কী তৈরি করা হয়েছে?

Users page-এ একটি DataTable আছে। Add User চাপলে modal form আসে। Form submit, edit, delete এবং status change—সবগুলো AJAX request দিয়ে হয়। কাজ সফল হলে শুধু Users page-এর content আবার load হয়; browser-এর পুরো page reload হয় না।

Button click→jQuery AJAX→Laravel Route→Controller→Database→DataTable refresh

কোন ফাইল কী কাজ করে?

ফাইলকাজ
routes/web.phpপ্রতিটি AJAX URL বা endpoint নির্ধারণ করে।
app/Http/Controllers/AdminController.phpValidation করে এবং database create/update/delete/status পরিবর্তন করে।
app/Models/Admin.phpDatabase field, password hashing এবং status boolean conversion নির্ধারণ করে।
resources/views/admin/accounts/partials/admin-user-content.blade.phpUsers table, action buttons এবং Add/Edit modal form রাখে।
resources/views/admin/layout/layout.blade.phpGlobal JavaScript: AJAX request, error message ও DataTable refresh রাখে।

১. Routes

এই routes-গুলো admin.auth middleware-এর মধ্যে আছে, তাই login ছাড়া কেউ এগুলো ব্যবহার করতে পারবে না।

Route::get('users', [AdminController::class, 'users'])->name('admin-user');
Route::post('users', [AdminController::class, 'storeUser'])->name('admin-user.store');
Route::get('users/{user}', [AdminController::class, 'showUser'])->name('admin-user.show');
Route::put('users/{user}', [AdminController::class, 'updateUser'])->name('admin-user.update');
Route::patch('users/{user}/status', [AdminController::class, 'updateUserStatus'])->name('admin-user.status');
Route::delete('users/{user}', [AdminController::class, 'deleteUser'])->name('admin-user.delete');

মনে রাখবেন: একই users/{user} URL হলেও HTTP method আলাদা হওয়ায় Laravel বুঝতে পারে কোন কাজ হবে। GET = data নেওয়া, PUT = update, DELETE = remove।

২. Model: password কেন নিরাপদ?

fillable দিয়ে কোন field save করা যাবে তা বলা হয়েছে। password => hashed থাকার কারণে plain password database-এ যায় না; Laravel hash করে রাখে।

protected $fillable = ['ap_id', 'name', 'type', 'mobile', 'email', 'password', 'status'];
protected $hidden = ['password'];

protected function casts(): array
{
    return ['password' => 'hashed', 'status' => 'boolean'];
}

৩. Controller: Add ও Update

public function storeUser(Request $request)
{
    Admin::create($this->validateUser($request));
    return response()->json(['message' => 'User added successfully.'], 201);
}

public function updateUser(Request $request, Admin $user)
{
    $user->update($this->validateUser($request, $user));
    return response()->json(['message' => 'User updated successfully.']);
}

response()->json() ব্যবহার করা হয়েছে কারণ AJAX JavaScript HTML redirect নয়, JSON response আশা করে।

Validation

private function validateUser(Request $request, ?Admin $user = null): array
{
    $data = $request->validate([
        'name'     => ['required', 'string', 'max:100'],
        'email'    => ['required', 'email', Rule::unique('admins', 'email')->ignore($user)],
        'password' => $user ? ['nullable', 'string', 'min:6'] : ['required', 'string', 'min:6'],
        'status'   => ['required', 'boolean'],
    ]);

    // Edit করার সময় password খালি থাকলে পুরোনো password অপরিবর্তিত থাকবে।
    if ($user && blank($data['password'] ?? null)) unset($data['password']);
    return $data;
}

৫. AJAX দিয়ে form save

function saveUserForm(url, method) {
    var data = $('#user-form').serializeArray();
    data.push({ name: '_method', value: method });

    $.post(url, $.param(data))
        .done(function (response) {
            // Modal বন্ধ করে শুধু বর্তমান content পুনরায় load করে।
            bootstrap.Modal.getInstance(document.getElementById('user-form-modal')).hide();
            window.loadAjaxPage(window.location.href, false);
        })
        .fail(function (xhr) {
            // 422 হলে Laravel validation messages modal-এ দেখায়।
            if (xhr.status === 422) showUserFormErrors(xhr.responseJSON.errors);
        });
}

_method হলো Laravel method spoofing। Browser form শুধু GET/POST পাঠাতে পারে, তাই POST-এর সঙ্গে _method=PUT পাঠিয়ে update route চালানো হয়েছে।

৬. Delete ও Status update

// Status toggle
$.post(statusUrl, { _token: csrfToken, _method: 'PATCH' })
 .done(function () { window.loadAjaxPage(window.location.href, false); });

// Delete
$.post(deleteUrl, { _token: csrfToken, _method: 'DELETE' })
 .done(function () { window.loadAjaxPage(window.location.href, false); });

প্রতিটি POST request-এ _token যায়। এটি Laravel CSRF protection-এর জন্য জরুরি। Delete-এর আগে browser confirmation দেখানো হয়। Controller logged-in user-কে নিজে delete করতেও বাধা দেয়।

Category, Section, Post-এ একই reusable CRUD ব্যবহার

নতুন নিয়ম: আর নতুন JavaScript event লিখতে হবে না। Shared CRUD engine layout.blade.php-এ একবার লেখা আছে। নতুন module-এর button/form-এ নিচের attributes দিলেই সেটি কাজ করবে।

<button data-crud-create

        data-create-title="Add Category">Add Category</button>

<button data-crud-edit data-crud-modal="#category-form-modal"
        data-url="/admin/categories/5"

<button data-crud-status data-url="/admin/categories/5/status">Active</button>
<button data-crud-delete data-url="/admin/categories/5">Delete</button>

<form data-crud-form> ... @csrf ... </form>
<table data-crud-table>...</table>

Section module-এ এই reusable attributes দেওয়া হয়েছে। Save, Update, Status ও Delete সফল হলে একই SweetAlert toast দেখায়:

Swal.fire({
  position: 'top-end', icon: 'success',
  title: 'Your work has been saved',
  showConfirmButton: false, timer: 1500
});
নতুন Category/Post বানানোর কাজ: শুধু তাদের model, migration, 6টি route, validation controller এবং table/modal Blade তৈরি করবেন। Shared JavaScript আর কপি করতে হবে না।

সমস্যা হলে কী দেখবেন?

  • 419 error: form-এ @csrf আছে কি না দেখুন।
  • 422 error: validation error; modal-এর error box দেখুন।
  • Route not defined: php artisan route:list --path=admin/users চালান।
  • পুরোনো Blade দেখালে: php artisan view:clear চালান।
  • DataTable দুই বার initialize error: initialize করার আগে $.fn.dataTable.isDataTable() check রাখতে হবে।
