Admin Permission — সহজ A–Z গাইড

১. এক কথায় system কী করে?

Admin user-এর জন্য checkbox select → Save → admin_roles table update → user page refresh করলে sidebar/button automatic hide বা show হবে।

এখানে আলাদা config file নেই। Permission page-এর module নাম সরাসরি database-এর admin_roles.module column থেকে আসে।

২. Database-এ কী আছে?

Table নাম: admin_roles। একটি row মানে একটি user-এর একটি module-এর permission।

Columnকাজ
admin_idকোন user-এর permission
moduleModule নাম: admin, section, category
view_accessSidebar menu ও list/page দেখতে পারবে
add_accessAdd/create করতে পারবে
edit_accessEdit, update এবং status change করতে পারবে
delete_accessDelete করতে পারবে
no_accessসব access বন্ধ করবে

৩. Permission page-এ module নাম কোথা থেকে আসে?

File: app/Http/Controllers/AdminController.php

permissionUser() method database থেকে unique module name নেয়:

$modules = AdminRole::select('module')
    ->distinct()
    ->orderBy('module')
    ->pluck('module');

তারপর admin-permission.blade.php ওই $modules loop করে checkbox দেখায়। তাই Blade file-এ admin / section / category manually লেখা নেই।

৪. Save চাপলে কী হয়?

  1. resources/views/admin/accounts/partials/admin-permission.blade.php checkbox form পাঠায়।
  2. resources/views/admin/layout/layout.blade.php AJAX দিয়ে submit করে এবং SweetAlert message দেখায়।
  3. AdminController::updatePermissionUser() request নেয়।
  4. AdminRole::updateOrCreate() দিয়ে ওই user + module-এর row create/update করে।

Full Access checkbox database-এ আলাদা column নয়। এটি shortcut: click করলে View, Add, Edit, Delete চারটিই 1 save হয়।

Module No Access দিলে অন্য চারটি 0 এবং no_access = 1 save হয়।

৫. Sidebar কীভাবে কাজ করে?

File: resources/views/admin/layout/sidebar.blade.php

এখানে তিনটি সহজ check আছে:

$canManageAdmins = $admin?->hasModuleAccess('admin', 'view');
$canManageSections = $admin?->hasModuleAccess('section', 'view');
$canManageCategories = $admin?->hasModuleAccess('category', 'view');

যার View Access নেই, তার menu show হবে না।

৬. User manually URL দিলে?

File: app/Http/Middleware/AdminPermissionMiddleware.php

এই middleware প্রতিটি route-এর আগে database permission check করে। তাই button/menu hide করাই একমাত্র security নয়। Permission না থাকলে server HTTP 403 দেয়।

৭. নতুন module যোগ করার সহজ নিয়ম

  1. প্রথমে admin_roles table-এ কোনো existing admin-এর জন্য নতুন module name-এর একটি row দিন। উদাহরণ: module = news।
  2. তারপর Permission page open করলে News Management automatic দেখা যাবে।
  3. নতুন News page-এর route-এ permission check এবং sidebar link যোগ করতে হবে। কারণ system জানবে না news কোন Laravel route/page-এর সঙ্গে যুক্ত।
বর্তমান project-এ sidebar-এ শুধু Users, Sections, Category page আছে। নতুন module-এর actual controller, route ও sidebar link তৈরি না করলে শুধু database row দিলেই কোনো নতুন page তৈরি হবে না।

৯. ব্যবহার করার নিয়ম

  1. Superadmin দিয়ে login করুন।
  2. Users → Permission চাপুন।
  3. প্রয়োজন অনুযায়ী View/Add/Edit/Delete select করুন, অথবা Full Access চাপুন।
  4. Save Permissions চাপুন।
  5. ওই user দিয়ে login/refresh করে ফল দেখুন।
কমপক্ষে একটি user-এর type = superadmin রাখবেন। Superadmin সবসময় access পাবে; তাই নিজের সব permission বন্ধ হয়ে যাওয়ার ভয় থাকবে না।
